## 🚀 About Me

I’m a software developer specializing in **full-stack web development** and **mobile application development**.

I enjoy building complete applications, working on both the frontend and backend, and turning ideas into practical and well-structured solutions.

My experience includes working with technologies such as **React, Node.js, Express.js, MongoDB, .NET, Laravel, and Flutter**, along with building and integrating **RESTful APIs** and working with different types of databases.

I’m especially interested in **backend development**, application logic, APIs, database design, and creating clean and responsive user interfaces.

I have hands-on experience building real-world projects, which helped me improve my problem-solving skills, understand how different parts of an application work together, and write cleaner and more organized code.

I’m always working on improving my skills, learning new technologies, and gaining more experience in areas related to **software architecture, backend development, system design, and modern application development**.
